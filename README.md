# 🛠️ RS7Z

> **The Native 7-Zip Experience for Unix-like Systems**
> *Because Igor Pavlov hasn't ported it to macOS/Linux yet.*

**RS7Z** is a **Rust**-powered, open-source re-implementation of the legendary [7-Zip](https://7-zip.org) archiver. While the original 7-Zip remains a Windows-only titan (Version 26.00, Feb 2026), RS7Z brings that same high-compression-ratio power to macOS and Linux ecosystems.

It's not just a wrapper; it's a ground-up rebuild for the terminal-savvy and the GUI-lovers alike.
